# Check Your Age

A simple Python project that calculates a person's age from their birth year.
It is a small beginner-friendly program built to practice functions, user input, arithmetic, and clean output formatting.

## About

`check_your_age` is a command-line Python program. The user enters their name and birth year, and the program calculates their age based on the current year used in the script.

This project is simple, but it represents an important step in learning how real programs receive input, process data, and return a useful result.

## Features

- Takes the user's name as input
- Takes the user's birth year as input
- Calculates age using a Python function
- Displays a personalized message
- Beginner-friendly and easy to understand

## Project File

- `age_count.py` - Main Python program for calculating age

## How to Run

Make sure Python is installed on your computer, then run:

```bash
python age_count.py
```

## Example

```text
Enter your name: Muna
Enter your birth year: 2005
Hello Muna! You are 21.
```
